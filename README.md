Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun — one funny line, judged head-to-head by an AI comedy-club judge.

## The joke

> I told my toddler babies come from the cloud. Now she asks Alexa for a little brother.

## How it works

`main.py` is deterministic (no network, no randomness). Run it and it writes the joke line to `entry.txt` (and to `/output/entry.txt` when the harness mounts it):

```sh
python3 main.py
```
